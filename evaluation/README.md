## Evaluation

Our evaluation is split into two parts: Manual and Automatic

### Manual Evaluation 
Manual Evaluation will be done by each group member and determined based on these metrics on a scale of (1-6):
Scale of 1-6 
Does it look like a portfolio that someone with this job would have (visually fitting and appealing)? 
Would you hire someone if they had this portfolio? 
Is the content captured well from the resume? 
Is the content captured well compared to their actual portfolio? 
Is the language used in the portfolio very resume-like (bullet points and metrics instead of complete sentences)? 
Did the generated portfolio have any made-up facts/hallucinations? 

### Automatic Evaluation
Automatic Evaluation will be done via a script (BERTScore_and_ROUGE.py) and is used to evaluated the text generated by our model
