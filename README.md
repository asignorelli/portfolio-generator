# Portfolio Generator

Takes a resume, asks Claude to generate a portfolio website from it, and evaluates how good the result is compared to the person's real portfolio.

## How it works

1. Give Claude a resume from `data/resumes/` along with the prompt in `prompt_v1.md`.
2. Save the generated portfolio in `output/html/`.
3. Compare it to the real portfolio in `data/portfolios/` using the automatic and manual evaluations in `evaluation/`.

## Folders

| Path | What it contains |
|---|---|
| `data/` | Resumes and the matching real portfolios |
| `output/` | Portfolio HTML files generated by Claude |
| `evaluation/` | Automatic metrics (BERTScore, ROUGE) and manual rating files |
| `prompt_v1.md` | The prompt given to Claude to generate portfolio HTML files|

## Naming

Every sample uses the same 4-digit ID across all folders (`0001`, `0002`, ...), so a resume, its real portfolio, its generated portfolio, and its ratings are easy to match up. This also helps with privacy.
